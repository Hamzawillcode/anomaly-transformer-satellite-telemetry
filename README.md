# Anomaly Transformer-Based Satellite Telemetry Anomaly Detection

Anomaly Transformer-based anomaly detection for the ESA-ADB Mission 1 satellite telemetry benchmark, with a custom preprocessing pipeline, Zero-Order Hold resampling, channel-aware normalization, telecommand encoding, and comprehensive evaluation.

## Overview

Satellite telemetry consists of high-dimensional, multivariate time-series data generated by spacecraft sensors, subsystems, and telecommands. Anomalies are often rare, short-lived, and distributed across multiple channels, making reliable detection challenging.

This project investigates transformer-based anomaly detection on the **ESA Anomaly Detection Benchmark (ESA-ADB) Mission 1** dataset using an adapted **Anomaly Transformer** architecture.

The work focuses on:

- Preprocessing irregularly sampled satellite telemetry
- Aligning telemetry channels using Zero-Order Hold (ZOH) resampling
- Handling heterogeneous signal types
- Encoding sparse telecommand events
- Addressing training instability caused by sparse telecommand channels
- Training an adapted Anomaly Transformer
- Evaluating anomaly scores and classification performance
- Visualizing association discrepancy and learned attention behaviour

A future phase of the research will investigate the reliability of LLM-generated explanations for detected anomalies using the AXIS framework.

---

## Research Objective

The main research direction is:

> **Can transformer-based anomaly detection reliably identify anomalous patterns in satellite telemetry, and can future LLM-generated explanations be evaluated for faithfulness to the underlying time-series evidence?**

The current repository focuses primarily on the **data preprocessing and anomaly detection stages**.

## Dataset

The experiments use the **ESA-ADB Mission 1** satellite telemetry benchmark.

### Dataset characteristics

| Property | Value |
|---|---|
| Dataset | ESA-ADB Mission 1 |
| Total features | 106 |
| Telemetry channels | 76 |
| Telecommand channels | 30 |
| Training split | 60% |
| Validation split | 20% |
| Test split | 20% |
| Training data | ~8.84M timestamps |
| Anomaly rate | ~10–12.2% across splits |
| Signal types | Continuous, binary, categorical |

The raw dataset is **not included in this repository**.

This is intentional because the repository is intended to contain the implementation, experimental results, and trained model rather than redistribute the raw benchmark data.
